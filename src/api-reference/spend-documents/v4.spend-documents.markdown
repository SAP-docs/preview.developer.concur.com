# Spend Documents v4 - Getting Started

Spend Documents v4 offers APIs for ingesting and retrieving receipt documents which will be made available in Concur Expense. The APIs support two workflows:

* **Simple Receipt**: Upload a receipt image with basic metadata. The uploaded receipt will be processed and visible in Available Receipts/Documents within Concur Expense.
* **eReceipt**: Submit structured electronic receipt data from partner/vendor systems directly into the Concur Expense platform, eliminating the need for users to manually capture and upload receipt images.

## Prior Versions

* [Receipts v4](/api-reference/receipts/get-started.html) was previously used for eReceipt submissions. New integrations should use Spend Documents v4.

## Limitations

Access to this documentation does not provide access to the API.

## Products and Editions

* Concur Expense Professional Edition
* Concur Expense Standard Edition

## <a name="prerequisites"></a>Prerequisites

Read the [Getting Started](https://developer.concur.com/api-reference/authentication/getting-started.html) section of [Authentication API](https://developer.concur.com/api-reference/authentication/apidoc.html). Once you have registered your application, you must [obtain an access token from the Authentication API](https://developer.concur.com/api-reference/authentication/getting-started.html).

For eReceipt partner/vendor integrations, you also need:

* An active partnership agreement with SAP Concur
* OAuth 2.0 client credentials with the appropriate scopes
* The ability to identify Concur users by `userId` and `companyId`

## Scope Usage

| Name | Description | Endpoint |
| --- | --- | --- |
| `spenddocs.receipts.write` <br> `spenddocs.receipts.writeOnly` | Post receipt for the user | POST |
| `spenddocs.receipts.read` | Retrieve receipt and its representations either by Receipt Id or Image Id and Company Id | GET |
| `spenddocs.receipts.compliance.write` | Post a compliance document alongside the receipt | POST |
| `spenddocs.receipts.compliance.read` | Retrieve compliance representation of the receipt | GET |

## eReceipt Categories

The eReceipt workflow supports the following receipt categories. Each category has specific schema requirements for the `receiptData` object.

| Category | Use Case | Category-Specific Details Object |
| --- | --- | --- |
| `general` | Restaurants, retail, and general purchases | None |
| `groundTransport` | Taxi, rideshare, and ground transportation | `tripDetails.rideDetails` |
| `lodge` | Hotels and accommodations | `tripDetails.lodgeDetails` |
| `air` | Airline tickets and flight bookings | `tripDetails.airDetails` |
| `carRental` | Vehicle rental transactions | `tripDetails.carRentalDetails` |
| `rail` | Train and rail travel | `tripDetails.railDetails` |
